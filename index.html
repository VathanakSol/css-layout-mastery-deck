Context

The layout stack moved from hacks to intent

Each generation solved a narrower problem better than the last.

Tables & floats

Structural markup was used as a positioning workaround. Content order and presentation became tangled.

Flexbox

A true alignment system for rows or columns, with flexible sizing and predictable distribution of space.

Grid

An explicit two-dimensional canvas for tracks, areas, overlap, and page-level composition.

Intrinsic CSS

`min()`, `clamp()`, container queries, subgrid, and `:has()` let components respond to their own context.

02 / 06
One dimension

Flexbox distributes space along an axis

Use it when items need to align, wrap, grow, or shrink in a row or column.

.toolbar {
  display: flex;
  gap: 12px;
  align-items: center;
  justify-content: space-between;
}
.label { flex: 1 1 auto; }
.action { flex: 0 0 auto; }

Mental model

  • `flex-grow` claims leftover space.
  • `flex-shrink` protects against overflow.
  • `flex-basis` sets the starting size.
  • `gap` replaces margin hacks between siblings.

Two dimensions

Grid composes rows, columns, and named areas

Describe the container’s structure first, then place content into it.

.app {
  display: grid;
  grid-template-columns: 240px 1fr 300px;
  grid-template-areas:
    "nav main aside";
  gap: 20px;
}
A track definition belongs to the parent; placement can belong to each child.

Strategy

Choose layout by behavior, not screen size alone

Combine fluid tracks, intrinsic limits, and component-aware breakpoints.

Start intrinsic

Use `repeat(auto-fit, minmax(260px, 1fr))` before writing media queries.

.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(260px, 1fr));
}

Add constraints

`clamp()` prevents type and spacing from becoming too small or too large on extreme viewports.

Query the container

Container queries make reusable components adapt wherever they are placed, rather than relying only on viewport width.

  • Card in sidebar → compact
  • Same card on page → expanded
  • Layout remains portable

05 / 06
Takeaway

When nothing lines up, inspect the contract

Most layout bugs come from conflicting assumptions between parent and child.

✓
Is display applied?
The parent owns `flex` or `grid`; children cannot opt in.
✓
Are axes clear?
Check `flex-direction`, wrapping, and cross-axis alignment.
✓
What is constraining size?
Review min/max values, aspect ratios, padding, and overflow.
Pick Flexbox for navigation bars, toolbars, cards in a line, and centered stacks.
Pick Grid for dashboards, editorial pages, app shells, and repeated tracks.
Use both: Grid establishes regions; Flexbox arranges content inside them.

Layout mastery

Modern CSS makes structure declarative. Name the relationship you want—grow, shrink, align, span—and let the browser calculate the rest.
